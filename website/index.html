От файла до ридера — один понятный маршрут.

  1. 1

    Подключите ридер

    По Wi-Fi: подключите устройства к общей сети, откройте адрес из BRIZFI в браузере ридера и подтвердите связь. Или выберите USB.

  2. 2

    Выберите книги

    Добавьте файлы в приложение. EPUB и FB2 можно подготовить для Kindle, а готовый AZW3 — передать без преобразования.

  3. 3

    Передайте и читайте

    При Wi-Fi скачайте книгу со страницы в браузере ридера. При USB отправьте её из приложения. Затем откройте книгу на ридере.

Перед первым подключением

Какие ридеры подходят?

Передача и открытие тестовых книг подтверждены на Kindle Basic 2024. Для Windows также подтверждена передача EPUB по USB на NOOK. Другие модели и сочетания способов подключения требуют отдельной проверки.

Какие форматы можно передавать?

Для Kindle предусмотрена подготовка EPUB и FB2 в AZW3; готовый AZW3 передаётся без изменений. Для поддерживаемого NOOK используется EPUB. Возможность открытия зависит от ридера. Книги с DRM не поддерживаются.

Как установить версию для Windows?

Кнопка скачивания загрузит ZIP для Windows x64 с GitHub. Распакуйте его целиком. Запустите brizfi.exe из распакованной папки. Папку data и DLL нужно сохранить рядом с программой.

Нужен ли интернет для передачи?

Для локальной передачи интернет не требуется. Для Wi-Fi устройства должны находиться в одной сети, а браузер ридера — открывать локальную страницу. Трафик HTTP не шифруется, поэтому используйте доверенную сеть. Интернет нужен для скачивания приложения.
