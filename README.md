# BRIZFI

Передача электронных книг с Android и Windows на ридер по локальной сети или USB.

- [Сайт и инструкция](https://mkulkov.github.io/brizfi-downloads/)
- [Скачать Windows x64](https://github.com/mkulkov/brizfi-downloads/releases/latest)
- [Android в RuStore](https://www.rustore.ru/catalog/app/ru.mkulkov.brizfi)
- [Исходники приложения](source/)
- [Сборка и состав релиза](BUILDING.md)

Windows: скачайте ZIP из Releases, распакуйте полностью и запустите `brizfi.exe`.
DLL и папка `data` должны оставаться рядом с EXE. Сборка не подписана цифровым сертификатом.
Запуск проверен на Windows 11 x64; чистая Windows без инструментов разработчика отдельно не проверялась.
При сообщении об отсутствующем MSVCP140/VCRUNTIME140 установите официальный
[Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

## Совместимость

Передача и открытие тестовых книг подтверждались на Kindle Basic 2024;
для Windows также подтверждалась USB-передача EPUB на NOOK.
Эти результаты относятся к конкретным аппаратным испытаниям, а не ко всем моделям.
Текущий опубликованный Windows-пакет прошёл сборку и проверку запуска;
повторная передача на физический ридер именно этим пакетом отдельно не проверялась.
EPUB и FB2 подготавливаются для Kindle в AZW3; AZW3 передаётся без преобразования.
DRM не обходится. HTTP в локальной сети не шифруется: используйте доверенную сеть.
iOS-исходники присутствуют, готовый iOS-релиз здесь не предоставляется.
